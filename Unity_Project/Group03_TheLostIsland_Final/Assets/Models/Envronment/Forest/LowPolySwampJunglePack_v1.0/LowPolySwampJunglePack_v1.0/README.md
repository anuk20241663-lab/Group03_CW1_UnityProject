# Low Poly Swamp & Jungle Pack (Free)
by reodesuxz

28 flat-shaded low poly swamp and jungle models: trees, plants, ruins, huts, boats and critters.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- SwampJungle_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 3408 triangles for all 28 models (40-212 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
